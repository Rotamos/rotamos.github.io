# Rotamos · Partidos de los clubes

  Web pública de consulta con los partidos, resultados y clasificaciones de
  los clubes que usan Rotamos. Sin registro ni contraseña.

  ## Clubes

  | Club | Enlace |
  |------|--------|
  | Club Dragons Moralzarzal | https://rotamos.github.io/dragons-moralzarzal/ |
  | Club Voleibol Collado Villalba | https://rotamos.github.io/cv-collado-villalba/ |

  ## Cómo funciona

  - La primera vez que entras puedes elegir ver todo el club o solo uno o
    varios equipos. La elección se guarda en tu navegador; puedes cambiarla
    cuando quieras con "Cambiar equipos".
  - Los datos se actualizan automáticamente cada hora los fines de semana y
    cada 12 horas entre semana. Al pie de cada página aparece la hora de la
    última actualización.
  - La web no recoge datos personales: no tiene cuentas, formularios ni
    cookies.
